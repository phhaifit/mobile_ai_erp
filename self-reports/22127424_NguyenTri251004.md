## 6. Tự đánh giá & rút kinh nghiệm (tùy chọn)

> Phần optional, không tính điểm — nhưng giúp thầy hiểu hơn về quá trình bạn làm việc.

### Điều bạn làm tốt:

> - Hoàn thành tốt các chức năng trọng tâm đúng tiến độ.
> - Chủ động thực hiện tích hợp Full-flow từ Frontend (Flutter) đến Backend (viết và tối ưu các API ), giúp quá trình ghép nối giữa FE và BE mượt mà hơn.
> - Tích cực review code, hỗ trợ các thành viên còn lại trong nhóm.

### Khó khăn bạn gặp phải:

> - Tính năng Dashboard có dữ liệu thống kê khá phức tạp, mất nhiều thời gian để bóc tách và xử lý phía Backend cũng như vẽ biểu đồ phía Frontend.
> - Tính năng Dashboard không có định nghĩa về insights rõ ràng, phải tự tìm hiểu về các insights quan trọng trong ứng dụng ERP tương tự để định nghĩa ra được bộ insights hợp lý.
> - Gặp một số khó khăn ban đầu trong việc đồng bộ logic dữ liệu giữa client và server trong Phase 2.

### Bạn sẽ làm khác đi điều gì nếu được làm lại:

> - Sẽ thống nhất API Contract thật kỹ với nhóm ngay từ đầu để hạn chế việc phải sửa đổi và cập nhật API nhiều lần trong quá trình tích hợp.
> - Chia nhỏ các Pull Request (PR) ra hơn nữa để tiến trình review code diễn ra nhanh chóng và hiệu quả hơn.
> - Chủ động làm rõ và chính xác các tài liệu về dự án từ ban đầu (như API docs, architechture document, PRD, ...) để có thể hiểu rõ dự án và để biết được mình đang build dự án đúng hay sai
